# Asymmetric Loss Functions

This repository presents the code and models from a study investigating "The Impact of Asymmetric Loss Functions on
Data-Driven Short-term Forecasting Approaches". Paper available at <>.

The research specifically addresses the challenge of volatile and inherently asymmetric error costs in production data, using the UNISIM-IV pre-salt petroleum field benchmark. We explore alternatives to the traditional metrics, such as Mean Squared Error (MSE).

**To run**

Execute the code below: 

<code>python main.py</code>

Make sure you configure your GPU device in the *DL_Regressors.py* file. 

The results will be stored in the generated *./Experiments/CSV/* folder.

For the dataset (located in the */U4_Data/* folder), don't hesitate to get in touch with us!
