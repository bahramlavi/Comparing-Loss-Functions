# Loss Functions for training Deep Learning Production Forecast Methods

This repository presents the code for the published work in the Journal of Scientific Reports, titled "Impact of Loss Function Selection on Deep Learning Methods for Oil and Water Production Forecasting in Offshore Reservoirs ". The original paper is available at <>.

The research specifically addresses the challenge of volatile and inherently error-prone costs in production data, it explores alternatives to the traditional metrics, such as Mean Squared Error (MSE).

**To run**

Execute the code below: 

<code>python main_U4.py</code>

Make sure you configure your GPU device in the *DL_Regressors.py* file. 

The results will be stored in the generated *./Experiments/* folder.

**Dataset**

For the UNISIM-IV dataset (located in the *./U4/* folder), please contact us!
